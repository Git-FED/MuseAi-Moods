Home / Deploy
Static by design

Ship it from the root.

No build step. No database. No plain-text fallback. The repository root is the publish directory.

GitHub Pages

Create or open the Muse-AI-Moods repository. In Settings → Pages, choose Deploy from a branch, select the default branch, and choose / (root).

Cloudflare Pages

Connect the GitHub repository to a Pages project, select the production branch, leave the build command empty, and set the output directory to . or the repository root.

Cloudflare Workers / Pages

The included wrangler.toml points Pages at the repository root. No server-side code is required for this site.

Local check

Run python3 -m http.server 8080 from the root, then open http://localhost:8080/.

Relative asset paths keep the site compatible with project subpaths and custom domains.
